# Changelog

All notable changes to API Explorer will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-29

### Added

- Initial release of API Explorer
- Browse, search, and explore 461 public APIs across 15 categories
- Dark theme desktop-like interface with search, filter, favorites, and recently viewed
- Live data proxy with cached fallback and offline mode
- Data integrity verification with checksum validation
- PyInstaller build support for desktop executable packaging
